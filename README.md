# ЯРБАТ-GAGARKA

#Основная идея
Проект представляет собой систему учета продаж и управления товарными остатками для сети торговых точек. Это внутренний инструмент для сотрудников, позволяющий:
#Фиксировать продажи — каждый работник отмечает заказы через простой интерфейс
#Контролировать финансы — раздельный учет наличных и безналичных платежей
#Управлять остатками — ведение складского учета и расходных материалов
#Анализировать эффективность — сбор статистики по каждому сотруднику и точке
